# Brew Counter – Coffee Shop Sales App

A simple point-of-sale web app: pick drinks, set size, apply a discount, take payment,
print a receipt, and view a sales report. Sales are saved in your browser (localStorage).

## Run it
No packages or installation needed. Unzip, then double-click `index.html`.
(Optional local server: `python -m http.server 8000` and open http://localhost:8000)

## Files
- index.html     page structure
- css/styles.css design (light and dark mode)
- js/data.js     YOUR MENU – edit names, prices, categories here
- js/app.js      cart, checkout, receipt, report, CSV export

## Notes
- Data stays on the device/browser used. Use "Export CSV" regularly as a backup,
  then open the CSV in Excel or SPSS/R for analysis.
- Clearing browser data deletes the sales history.
